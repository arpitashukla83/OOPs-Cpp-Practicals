💻 Object Oriented Programming Using C++ – Practical Repository

📌 About This Repository

This repository contains all 13 practical experiments of the Object Oriented Programming using C++ Laboratory course.

The practicals are based on the ADYPU OOPs C++ syllabus for the academic year 2026–2027.

The main objective of this repository is to understand Object-Oriented Programming concepts and implement them through practical C++ programs.

🎯 Objectives

- Understand the fundamentals of C++ programming.
- Learn classes, objects, constructors and destructors.
- Implement the four pillars of OOP.
- Understand memory management and smart pointers.
- Practice inheritance and polymorphism.
- Learn templates and Standard Template Library (STL).
- Implement exception handling and file handling.
- Develop a real-world mini-project using C++.

📚 Practical List

No.| Experiment / Practical
01| C++ Basics: Data Types, Variables, Constants, Operators and I/O
02| Classes, Objects, Access Specifiers and Member Functions

04| RAII and Smart Pointers: unique_ptr and shared_ptr

13| Mini Project using OOP, STL and Exception Handling

⚙️ How to Run the Programs

Step 1: Clone the repository.

git clone https://github.com/your-username/OOPs-Cpp-Practicals.git

Step 2: Open the desired practical folder in VS Code.

Step 3: Compile the program.

g++ -std=c++17 main.cpp -o output

Step 4: Execute the program.

For Windows:

output.exe
