Object Oriented Programming Using C++ – Practical Repository

📌 About This Repository

This repository contains all 10 practical experiments and the Mini Project for the Object Oriented Programming Using C++ Laboratory course.

The practicals are based on the ADYPU OOPS C++ syllabus for the academic year 2026–2027.

The main objective of this repository is to understand Object-Oriented Programming concepts and implement them through practical C++ programs.

🎯 Objectives

- Understand the fundamentals of C++ programming.
- Learn classes, objects, constructors, and destructors.
- Understand access specifiers and member functions.
- Implement inheritance and polymorphism.
- Learn function and operator overloading.
- Understand templates and Standard Template Library (STL).
- Implement exception handling.
- Learn file handling using C++.
- Develop problem-solving skills through practical programming.

📚 Practical List

S.N.| Experiment Description
01| Set up a GitHub repository. Write a C++ program to demonstrate data types, constants, variables, operators, and I/O.
02| Design and implement a class hierarchy for a real-world entity (BankAccount, Vehicle). Demonstrate access specifiers and member functions.
03| Implement a class demonstrating all constructor types (Default, Parameterized, Copy, Move). Apply the Rule of 5. Verify with Valgrind for memory leaks.
04| Implement Single and Multilevel Inheritance for a university management scenario (Person → Student → GraduateStudent).
05| Demonstrate runtime polymorphism using virtual functions and an abstract base class. Implement a Shape hierarchy (Circle, Rectangle, Triangle) with an area() method.
06| Implement compile-time polymorphism: function overloading and operator overloading for a Matrix or Complex Number class.
07| Write a generic Stack or Queue class using templates. Test with int, float, and std::string.
08| Use STL containers (vector, map, unordered_map) and algorithms (sort, find_if, transform) to process a student marks dataset.
09| Create a custom exception hierarchy. Write a program that throws and catches specific exceptions for a banking transaction scenario.
10| Implement a CSV file reader/writer using file I/O (fstream). Store and retrieve student records. Use file pointers (seekg, seekp, tellg, tellp).
11| MINI PROJECT

▶️ How to Compile and Run

1. Clone this repository:

git clone https://github.com/arpitashukla83/OOPs-Cpp-Practicals.git

2. Open the required experiment folder.

3. Compile the C++ program:

g++ main.cpp -o main

4. Run the program:

./main

For Windows:

main.exe
